# StoreX ☁️

**StoreX** is a full-stack cloud storage platform inspired by Google Drive and Dropbox. It enables users to securely manage files, organize folders, and access their digital content through a modern, responsive interface.

Built with React, Node.js, Express.js, and Neon, the application combines a responsive frontend with backend APIs, PostgreSQL database management, and cloud-based file storage.

## ✨ Features

- **Authentication:** User signup and login.
- **File Management:** Upload, preview, download, and manage files.
- **Folder Organization:** Create folders and organize files efficiently.
- **Move Operations:** Move files and folders between locations.
- **Trash & Restore:** Move items to trash and restore them when needed.
- **Permanent Deletion:** Permanently delete files and folders.
- **File Sharing:** Generate shareable links for files and folders.
- **Cloud Storage:** Store application data and uploaded files in the cloud.
- **Responsive UI:** Access the application through a modern, responsive interface.

## 🎯 Project Objective

The goal of StoreX is to explore full-stack web development by implementing authentication, REST APIs, database operations, file handling, and cloud storage in a practical application.
